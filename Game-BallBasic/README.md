# Neon Depths

Neon Depths é um jogo de ação em perspectiva superior, inspirado por roguelikes e shooters arcade, desenvolvido em Python com Pygame. O jogador explora andares com temática cyberpunk, enfrenta inimigos, coleta power-ups e tenta sobreviver até os chefes finais.

## ✨ Características

- Jogabilidade rápida com movimentação, dash e tiros
- Mapas com estilo de dungeon e atmosfera neon
- Sistema de ondas de inimigos e chefes a cada certos andares
- Power-ups para aumentar vida, energia, dano e velocidade
- Interface com HUD, notificações e feedback visual
- Sistema de save, conquistas e leaderboard
- Menu de configurações com opção de tela cheia e volumes

## 🛠️ Tecnologias

- Python 3
- Pygame
- JSON para salvamento de progresso e estatísticas

## 📋 Requisitos

- Python 3.10+
- pip

## ▶️ Instalação

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/Game-BallBasic.git
cd Game-BallBasic
```

2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Execute o jogo:

```bash
python main.py
```

Se o comando `python` não estiver disponível no seu sistema, tente:

```bash
py main.py
```

## 🎮 Controles

- WASD ou setas: movimentação
- Mouse: mira e atira
- Espaço: dash
- Esc ou P: pausar

## 🧩 Estrutura do projeto

- `main.py`: ponto de entrada do jogo e loop principal
- `player.py`: lógica do jogador
- `enemy.py`: inimigos e IA
- `bullet.py`: balas e projéteis
- `map.py`: geração e estrutura dos mapas
- `ui.py` e `menu.py`: interface e menus
- `utils/`: câmera, áudio, colisão, save system, leaderboard e demais utilidades

## 🎯 Objetivo do jogo

Sobreviva aos andares, elimine inimigos, recupere recursos e avance até o limite do caos neon. Cada andar aumenta a dificuldade e prepara o jogador para novos desafios.
